= DII MCP 서버
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
AI 어시스턴트/에이전트를 Data Infrastructure Insights(DII)에 연결하여 자연어를 사용하여 인프라 인벤토리, 원격 측정 데이터, 경고 및 데이터 수집 상태를 조사할 수 있도록 합니다.


NOTE: DII MCP는 link:concept_preview_features.html["시사"] 기능이므로 변경될 수 있습니다.

DII MCP 서버는 모델 컨텍스트 프로토콜(MCP)을 구현하고 지원되는 AI 클라이언트에 테넌트 범위 툴을 제공합니다. 현재 제품 툴셋은 *읽기 전용*입니다. DII 데이터를 검색하고 분석하지만 인프라 또는 DII 리소스를 수정하지는 않습니다.



[[what-you-can-investigate]]
== 조사할 수 있는 사항

* *인프라 인벤토리:* 스토리지, 가상화, Kubernetes, ONTAP, Azure NetApp Files, StorageGRID 및 관련 리소스.
* *성능 및 용량:* 오브젝트 메트릭, 그룹화된 집계 및 시계열 동작.
* *로그 및 이벤트:* 로그 유형을 확인하고, 이벤트를 검색하고, 이벤트 발생 횟수 히스토그램을 생성합니다.
* *경고:* 활성 경고, 모니터 정의, 심각도 및 시정 지침을 검토합니다.
* *컬렉션 상태:* 수집 단위, 데이터 소스, 지원되는 컬렉터 유형 및 Kubernetes 컬렉터 버전을 검토하십시오.
* *알림 설정:* 유지보수 윈도우, 알림 규칙 및 웹훅 대상 유형을 검토하십시오.

[[how-dii-mcp-queries-work]]
== DII MCP 쿼리 작동 방식

많은 DII 리소스는 동적 스키마를 가지고 있습니다. 신뢰할 수 있는 조사는 발견 우선 순서를 따릅니다:

. 사용 가능한 오브젝트 또는 로그 유형을 나열하십시오.
. 선택한 유형에 대한 메타데이터를 검색합니다.
. 해당 메타데이터에서 유효한 속성과 메트릭만 사용하십시오.
. 특정 시간 범위를 지정하여 조회합니다.
. 필터, 그룹화, 정렬 또는 페이지네이션을 사용하여 결과를 세분화하세요.


자세한 내용은 link:mcp_concepts.html["개념 및 데이터 모델"]을 참조하십시오.



[[important-limitations]]
== 중요한 제한 사항

* 현재 모든 제품 툴은 읽기 전용입니다.
* 오브젝트, 성능 및 로그 쿼리는 제한된 시간 범위를 적용합니다. 툴 페이지에 더 짧은 제한이 명시적으로 나와 있지 않는 한 30일 이하의 시간 범위를 사용하십시오.
* 쿼리 필드는 선택한 리소스 유형에 대해 반환된 메타데이터와 일치해야 합니다.
* 대규모 결과는 페이지로 나뉘거나 제한됩니다.
* 툴 사용 가능 여부 및 반환되는 데이터는 테넌트의 수집기, 활성화된 기능 및 사용자 권한에 따라 달라집니다.
* 웹훅 엔드포인트의 전체 주소를 요청하거나 복제하지 마십시오. link:mcp_security.html["보안 및 개인정보 보호"]을(를) 참조하십시오.
