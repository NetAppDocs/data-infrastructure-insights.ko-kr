= 워크로드 보안 에이전트 삭제
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
호스트를 더 이상 사용하지 않거나 컬렉션을 다른 에이전트로 통합할 때 에이전트를 삭제하십시오. 에이전트를 삭제하면 해당 에이전트에 할당된 모든 컬렉터도 함께 삭제됩니다.

[cols="100%"]
|===
| *에이전트를 삭제하면 남은 수집기도 삭제됩니다.* 에이전트에 여전히 할당되어 있는 모든 데이터 수집기 또는 사용자 디렉터리 수집기는 에이전트와 함께 제거되며, 이후에는 구성을 복구할 수 없습니다. 에이전트를 삭제하기 전에 필요한 구성을 기록하거나 이동하십시오. 
|===


[[decide-what-you-want-to-keep]]
== 무엇을 남길지 결정하세요

[cols="37%,63%"]
|===
| *목표* | *해야 할 일* 


| 다른 에이전트에서 동일한 스토리지를 계속 수집하십시오. | 이 에이전트를 삭제하기 전에 각 수집기를 다른 에이전트로 이동하십시오. 수집기를 다시 생성하는 대신 재할당하여 수집이 중복되지 않도록 하십시오. 


| 이 스토리지에서 수집을 완전히 중지하십시오. | 에이전트를 삭제합니다. 해당 에이전트에 할당된 수집기도 동시에 삭제됩니다. 


| 새 호스트에서 에이전트를 다시 빌드합니다 | 먼저 각 수집기의 구성을 기록하고, 새 에이전트를 배포한 다음, 수집기를 다시 생성하거나 이동하십시오. 
|===


[[before-you-begin]]
== 시작하기 전에

* Data Infrastructure Insights 관리자 또는 계정 소유자로 로그인하십시오. 에이전트를 삭제하려면 관리자 권한이 필요합니다.
* 이름으로 에이전트를 확인하고 에이전트 상세 페이지에서 해당 에이전트에 할당된 수집기를 검토하십시오.
* 계속 필요한 수집기 구성은 모두 저장해 두십시오. 삭제된 수집기 구성은 복구할 수 없습니다.
* 이 에이전트에 할당된 모든 컬렉터를 해당 에이전트를 참조하는 모든 경고 정책에서 제거하십시오. 경고 정책에서 여전히 참조되는 컬렉터가 있는 경우 삭제가 차단됩니다.


[cols="100%"]
|===
| *에이전트를 일시 중지하거나, 고정을 해제하거나, 업그레이드를 기다릴 필요가 없습니다.* 일시 중지, 재개, 고정 및 고정 해제는 에이전트 삭제에 영향을 미치지 않습니다. 예약되었거나 진행 중인 에이전트 및 수집기 작업도 에이전트 삭제를 차단하지 않습니다. 
|===


[[choose-the-procedure-that-matches-your-agent]]
== 에이전트에 맞는 절차를 선택하십시오.

에이전트 목록에는 각 에이전트의 상태가 표시됩니다. 에이전트를 삭제하기 전에 수행해야 할 작업은 해당 에이전트가 여전히 연결되어 있는지 여부에 따라 다릅니다.

[cols="21%,62%,17%"]
|===
| *에이전트 상태* | *Workload Security에 필요한 사항* | *사용* 


| 연결됨 | 모든 데이터 수집기와 User Directory Collector는 에이전트에서 먼저 제거해야 합니다. 수집기 상태는 중요하지 않습니다. 중지된 수집기도 포함됩니다. | 절차 A 


| 연결되지 않음 | 수집기를 먼저 제거할 필요는 없습니다. 여전히 할당된 수집기는 에이전트와 함께 삭제됩니다. | 절차 B 
|===


[[procedure-a-delete-a-connected-agent]]
== 절차 A: 연결된 에이전트 삭제

*1.* Workload Security ++>++ 수집기 ++>++ 에이전트를 선택한 다음 에이전트 이름을 선택하여 세부 정보를 엽니다.

*2.* 에이전트에 나열된 모든 데이터 수집기를 이동하거나 삭제합니다. 동일한 스토리지를 계속 수집하려면 수집기를 삭제하는 대신 다른 에이전트에 할당하십시오.

*3.* 에이전트에 나열된 모든 사용자 디렉터리 수집기를 이동하거나 삭제합니다.

*4.* Workload Security ++>++ 수집기 ++>++ 에이전트로 돌아갑니다.

*5.* 에이전트의 옵션 메뉴를 선택한 다음 삭제를 선택합니다.

*6.* 에이전트 삭제 대화 상자에서 삭제를 확인합니다.

*7.* "에이전트 소프트웨어 제거"에 설명된 대로 호스트에서 에이전트 소프트웨어를 제거합니다.

image:ws-delete-agent-confirmation.png["샘플 에이전트 삭제를 확인하고 호스트에서 에이전트 소프트웨어를 제거하는 명령을 보여주는 에이전트 삭제 대화 상자.,title=\"에이전트 삭제 확인 대화 상자\",width=1007,height=562"]

[cols="100%"]
|===
| *대화 상자에 Cannot Delete Agent라고 표시되는 경우* 연결된 에이전트에 데이터 수집기 또는 사용자 디렉터리 수집기가 하나 이상 할당되어 있는 것입니다. 나머지 수집기를 제거하고 다시 시도하십시오. 방금 수집기를 제거한 경우 먼저 에이전트 페이지를 새로 고치십시오. 
|===


[[procedure-b-delete-a-retired-or-unreachable-agent]]
== 절차 B: 폐기되었거나 연결할 수 없는 에이전트 삭제

에이전트 호스트가 사용 중지되거나 이미 오프라인 상태이고 해당 호스트에 할당된 수집기가 더 이상 필요하지 않은 경우 이 절차를 사용하십시오.

*1.* 이 에이전트에 할당된 수집기가 더 이상 필요하지 않은지 확인하십시오. 해당 수집기는 에이전트와 함께 삭제됩니다.

*2.* 호스트에 계속 연결할 수 있는 경우, "에이전트 소프트웨어 제거"에 설명된 대로 에이전트 소프트웨어를 제거하십시오.

*3.* Workload Security ++>++ Collectors ++>++ Agents를 선택하고 Agent에 Not Connected가 표시될 때까지 기다립니다.

*4.* 에이전트의 옵션 메뉴를 선택한 다음 삭제를 선택합니다.

*5.* 에이전트 삭제 대화 상자에서 삭제를 확인합니다.



[[uninstall-the-agent-software]]
== 에이전트 소프트웨어 제거

Workload Security에서 에이전트를 삭제하면 클라우드 측 구성이 제거됩니다. 호스트에서 소프트웨어가 제거되는 것은 아니므로 호스트를 폐기할 때 별도로 제거해야 합니다.

*1.* 에이전트 호스트에서 터미널 세션을 엽니다.

*2.* 제거 명령을 실행하고 메시지가 나타나면 y를 입력하십시오.

[listing]
----
sudo cloudsecure-agent-uninstall.sh
----
제거 프로그램은 에이전트 서비스를 중지하고 비활성화하며 설치 디렉터리를 제거합니다. 확인 메시지 없이 제거하려면 -n 옵션을 추가하십시오.



[[verify-the-deletion]]
== 삭제를 확인합니다

* 에이전트가 더 이상 Workload Security ++>++ Collectors ++>++ Agents에 나타나지 않습니다.
* 이에 할당된 수집기가 더 이상 수집기 목록에 나타나지 않습니다.
* 소프트웨어를 제거했다면 호스트에 에이전트 서비스가 더 이상 존재하지 않습니다.




[[troubleshooting]]
== 문제 해결

[cols="39%,61%"]
|===
| *메시지 또는 증상* | *원인 및 해결책* 


| 에이전트를 삭제할 수 없습니다: "++<++Agent++>++에 구성된 모든 데이터 수집기를 삭제하십시오." | 에이전트가 연결되어 있고 데이터 수집기 또는 사용자 디렉터리 수집기가 하나 이상 할당되어 있습니다. 나머지 수집기를 이동하거나 삭제한 후 페이지를 새로 고치고 다시 시도하십시오. 


| "에이전트를 삭제하기 전에 해당 정책에서 에이전트의 아래 장치를 제거하십시오." | 이 에이전트에 속한 수집기가 메시지에 언급된 경고 정책에서 여전히 참조되고 있습니다. 각 정책을 편집하여 해당 수집기를 제거하고 정책을 저장한 다음 삭제를 다시 시도하십시오. 


| 권한 오류로 인해 삭제가 실패합니다. | 에이전트를 삭제하려면 관리자 또는 계정 소유자 권한이 필요합니다. 다른 역할의 사용자는 에이전트 페이지를 열 수는 있지만 삭제를 완료할 수는 없습니다. 


| 해당 에이전트는 등록되지 않은 것으로 보고되었습니다. | 에이전트가 이미 삭제되었거나 다른 환경에서 작업 중입니다. 에이전트 페이지를 새로 고치고 에이전트 및 테넌트를 확인하십시오. 


| 에이전트는 Workload Security에서 사라졌지만 호스트에서는 여전히 실행 중입니다. | 에이전트를 삭제해도 소프트웨어는 제거되지 않습니다. 호스트에서 제거 명령을 실행하십시오. 


| 삭제된 컬렉터가 여전히 사용량을 소모하는 것으로 나타납니다. | 사용량은 각 보고 간격 동안 존재하는 수집기를 기준으로 보고됩니다. 더 이상 사용하지 않는 에이전트와 수집기는 삭제하고, 기존 수집기와 새 수집기가 겹치지 않도록 수집기를 새로 생성하는 대신 이동하십시오. 
|===
