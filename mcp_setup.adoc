[role="lead"]
이 가이드를 사용하여 MCP 호환 AI 클라이언트를 DII에 연결하십시오.


NOTE: DII MCP는 link:concept_preview_features.html["시사"] 기능이므로 변경될 수 있습니다.



[[before-you-begin]]
== 시작하기 전에

필요한 것:

* DII 테넌트에 대한 액세스.
* 쿼리하려는 리소스를 읽을 수 있도록 승인된 DII 사용자 또는 서비스 ID입니다.
* DII 환경에 제공되는 원격 MCP 엔드포인트입니다.
* 원격 HTTP 서버와 조직의 인증 방법을 지원하는 MCP 클라이언트.


예제에서는 +<DII_HOST_URL>+를 자리 표시자로 사용합니다. 액세스 토큰을 소스 제어 파일에 붙여넣지 마십시오. 예를 들어 Cursor에서 사용하는 URL은 다음과 같습니다:

 https://<DII_HOST_URL>/api/v1/mcp
사용 중인 연결에 맞는 구체적인 코드 조각을 참조하세요.



[[configure-the-mcp-client]]
== MCP 클라이언트를 구성합니다

. 관리자 > API 액세스로 이동하여 "MCP 구성" 탭을 선택하십시오.
. 구성할 클라이언트를 선택하십시오.
. 의미 있는 이름과 만료일을 입력하고 _Generate Token_을 선택합니다.
. *코드 조각을 복사하세요* 이 단계에서만 이 코드를 복사할 수 있습니다. 토큰은 코드 조각에 숨겨져 있지만 클라이언트 앱에 올바르게 붙여넣어집니다.
. 클라이언트 설정에서 "url" 필드에 올바른 DII 호스트 URL을 입력하십시오.
. 구성을 저장합니다.



IMPORTANT: 셸 기록, 프롬프트, 스크린샷, 프로젝트 파일 또는 소스 제어에 베어러 토큰을 두지 마십시오.



[[verify-access]]
== 접근 권한 확인

클라이언트가 서버에 연결되었다고 보고하면 다음과 같은 요청을 보낼 수 있습니다:

[]
====
내가 사용할 수 있는 DII 오브젝트 유형을 나열해 주세요. 내가 사용할 수 있는 DII 로그 유형을 나열해 주세요. IP 주소나 UUID를 표시하지 않고 내 수집 장치를 나열해 주세요.

====
검색에 성공하면 연결이 확인되지만, 모든 하위 리소스에 대한 액세스가 보장되는 것은 아닙니다. 테넌트 기능, 수집기 및 권한에 따라 반환되는 데이터가 결정됩니다.



[[credential-safety]]
== 자격증명 보안

* 가능하다면 대화형 OAuth 또는 다른 단기 자격 증명 흐름을 사용하는 것이 좋습니다.
* 무인 클라이언트에는 전용 서비스 ID를 사용하십시오.
* 프롬프트, 스크린샷, 예제, 문제 설명 또는 소스 코드 관리 시스템에 토큰을 넣지 마십시오.
* 에이전트에게 전체 웹훅 주소를 표시하도록 요청하지 마십시오.


추가 지침은 link:mcp_security.html["보안 및 개인정보 보호"]을(를) 참조하십시오.
